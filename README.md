# File Shredder

Windows приложение, което добавя опция **Shred** в контекст менюто на файлове и папки. Избраното се презаписва на място и се изтрива, без да минава през кошчето.

## Инсталиране

Стартирай `dist\FileShredder-Setup-1.0.0.exe`. Инсталацията е за текущия потребител и не иска администраторски права. Тя добавя **Shred** в контекст менюто, пряк път в Start и запис в Programs and Features, откъдето приложението се премахва напълно.

## Нова версия на инсталатора

Нужни са Flutter, Visual Studio с C++ и Inno Setup 6. Смени `AppVersion` в `installer/fileshredder.iss` и изпълни:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File installer/build.ps1
```

`AppId` в същия файл не трябва да се променя, защото по него Windows разпознава обновяванията.

В Windows 11 опцията е под **Show more options** (или Shift + десен бутон). За да е в горното меню, приложението трябва да е подписан MSIX пакет с `IExplorerCommand`.

## Какво се случва с всеки файл

1. Файлът се отваря с изключителен достъп. Ако е зает, остава непроменен.
2. Съдържанието и скритите NTFS потоци (ADS) се презаписват 3 пъти с криптографски случайни данни, като след всеки пас кешът се изпразва към диска.
3. Файлът се съкращава до 0 байта, преименува се на случайно име и се изтрива.

Броят на пасовете е `defaultPasses` в `lib/src/shredder.dart`.

## Предпазни мерки

- Винаги се иска потвърждение, а фокусът по подразбиране е на **Cancel**.
- Отказват се цели дискове, `Windows`, `Program Files`, потребителският профил и основните му папки, както и всяка папка, която ги съдържа.
- Символни връзки и junction-и не се следват: трие се само връзката, а целта остава.
- Файлове с hard links се пропускат, защото презаписът би унищожил данните и под другите имена.
- Файлове на OneDrive и други облачни услуги във вид на placeholder се пропускат.

## Ограничения: какво „безвъзвратно“ не покрива

Софтуерът може да презапише само това, което Windows му показва. Резултатът е сигурен основно за обикновени файлове върху HDD с NTFS.

- **SSD и флашки:** контролерът записва на нови клетки, така че старите може да останат физически. Сигурното решение е пълно криптиране на диска (BitLocker) или Secure Erase.
- **Копия извън файла:** снимки на диска (Volume Shadow Copy, System Restore), облачни версии, архиви, файлът за виртуална памет и хибернация, временни файлове на програми.
- **Компресирани, криптирани (EFS) и sparse файлове:** новите данни може да легнат в други клъстери.
- **Метаданни:** журналът на NTFS може да пази стари имена и времена за известно време.
